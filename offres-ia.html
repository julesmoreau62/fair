Crédits cloud

Ces crédits couvrent la consommation de services admissibles. Ils peuvent servir à héberger une application, stocker des documents ou intégrer un modèle d’IA à un outil métier.

Microsoft

2 000 $ US par an

Voir les détails Masquer les détails

Hébergez un outil qui recherche dans vos guides publics, avec une base de données et des services d’IA Azure admissibles. Dans Microsoft Foundry, vérifiez qui facture le modèle choisi. Le crédit couvre les services Azure fournis par Microsoft. Les offres tierces du Marketplace sont exclues.

Le crédit est renouvelable tant que l’association reste éligible. Le solde expire chaque année et les dépassements peuvent être facturés.

Avant de choisir

  1. Choisissez une tâche précise et testez-la sur un document déjà public. Relisez le résultat à partir de la source.
  2. Vérifiez les critères de votre structure, les données que l’outil conserve et les personnes qui y auront accès.
  3. Pour un projet cloud, vérifiez les services couverts, estimez le coût après la fin du crédit et configurez une alerte de facturation.
